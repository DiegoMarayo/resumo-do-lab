## Resumo — Computação em Nuvem (AZ-900)
### 📌 1. O que é Computação em Nuvem

Computação em nuvem é a entrega de serviços de TI (como armazenamento, servidores e bancos de dados) pela internet, permitindo acesso sob demanda e pagamento conforme o uso.


## 📌 2. Principais Benefícios
- Escalabilidade → aumenta ou reduz recursos facilmente
- Alta disponibilidade → serviços sempre acessíveis
- Elasticidade → adapta-se automaticamente à demanda
- Custo sob demanda (OpEx) → paga só pelo que usa
- Menos manutenção → responsabilidade fica com o provedor

## 📌 3. Modelos de Nuvem
- Nuvem Pública → infraestrutura de terceiros (ex: Azure, AWS, GCP)
- Nuvem Privada → usada por uma única organização, estrutura On-premise
- Nuvem Híbrida → mistura das duas


## 📌 4. Conceitos do Azure (Arquitetura)
- Regiões → locais físicos com datacenters
- Zonas de disponibilidade → redundância dentro da região
- Grupos de recursos → organização dos serviços
- Assinaturas → controle de acesso e cobrança

## 📌 5. Segurança e Responsabilidade Compartilhada
- A Microsoft cuida da infraestrutura
- O cliente cuida dos dados e configurações

## 📌 6. Custos e Governança
- Modelo pay-as-you-go (pague pelo uso)
- Ferramentas para:
- controle de custos
- compliance
- monitoramento
